# Hardware

Board, RAM, screen, battery, ports, and BOM target.

## Board
- Start with a Raspberry Pi 5 (4 GB+). Downgrade (Pi 4 or other) to be tested later if viable.

## Screen
- Target about 7 to 8 inches (roughly 16 x 12 cm, about 4:3). Larger costs weight and power; confirm against the weight limit.
- Text area up to 30 lines is enough; fewer is fine.
- Sharpness does not matter. Readability does.
- Battery draw matters; aim for a middle ground between draw and responsiveness.
- LCD. E-ink ruled out (too slow for a terminal).
- Colour is nice to have, not required.

## Deferred
- Storage, battery, cooling, keyboard connection (USB or Bluetooth), ports, enclosure.
